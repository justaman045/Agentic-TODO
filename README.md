## The Problem

Most task managers are either too simple or overly complex. Users struggle with:
- Poor scheduling
- Lack of habit building
- No intelligent prioritization
- Fragmented experience across devices

**Veltro** combines **AI intelligence** with beautiful mobile UX to solve these problems.

---

## Key Features

| Feature                    | Description |
|---------------------------|-------------|
| **AI Smart Scheduling**   | Automatically suggests optimal task timing |
| **Habit Streaks**         | Build and track daily/weekly habits |
| **Pomodoro Timer**        | Focus sessions with AI break recommendations |
| **Recurring Tasks**       | Smart recurring task management |
| **Real-time Sync**        | Seamless experience across Android & iOS |
| **Offline Support**       | Works without internet connection |
